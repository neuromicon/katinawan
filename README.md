# Katin-awan — Sacred Plant Spirit Healing

This repository contains the public information website for **Katin-awan**, a Sacred Plant Spirit Healing community in the Visayas, Philippines.

🌿 **Website:** https://neuromicon.github.io/katinawan

## What you'll find on the website

- **Gathering dates** – published upcoming gatherings
- **Photo gallery** – photographs from the community
- **Preparation guidance** – how to prepare before attending
- **Contact details** – how to reach the organizers
- **Welcome music** – soft background audio on opening, with mute and volume control

## Follow us

- Facebook: https://web.facebook.com/sacredplantspirithealing

## About this repository

This repository only hosts the website content. It is an information site, not an open-source project — it is not intended for collaboration, contributions, or pull requests.

To learn more or to join a gathering, please visit the website above or contact the organizers directly.
